# ゼミ試験アプリケーション

ゼミ入試 ── 履歴書・学力試験・アンケート ── をWEB上で受け付け、多面的に分析するシングルページWebアプリです。試験回ごとに完全に独立した問題セット・受付制御・分析を提供します。

## 主要機能

### 試験回（セッション）管理
- 複数の試験回を作成・名称変更・削除
- 試験回ごとに **学力試験の問題**・**アンケート項目**・**学部/学科の選択肢**・**履歴書追加質問**を独立カスタマイズ
- 各フェーズ（履歴書 / 学力試験 / アンケート）の受付ON/OFFを管理者が制御
- **基本情報**（試験日・試験場所・目標合格人数・備考）を試験回ごとに保存。ダッシュボードに進捗 (X/目標Y名) 表示

### 受験者向けポータル（URL/QRで配布）
- 配布用URLとQRコードを管理画面で生成
- 受験番号入力 → 受付中のフェーズが一覧表示 → クリックして回答
- 履歴書は必須、学力試験とアンケートは履歴書提出後に独立して回答可能

### 学力試験（自動採点）
- 選択式（任意の数の選択肢、各問配点設定可）
- 提出時に自動採点 → 受験者にも即時通知
- カテゴリ別の正答率を集計しレーダーチャートに反映

### アンケート（5段階評価）
- 試験回ごとに項目を自由作成
- 受験者の傾向をレーダーチャートで表示

### 履歴書
- 標準フィールド（受験番号・姓/名・フリガナ・連絡先・GPA・志望動機・自己PR・研究テーマ等）
- 学部 / 学科（管理画面で設定した選択肢からカスケード選択）
- 追加質問を試験回ごとに任意作成

### 全体確認（管理者ダッシュボード）
- 受験者数 / 各フェーズ提出状況 / 学力試験 最高・最低点 / 合格者数（目標との進捗 X/Y 名併記）
- **受験者一覧**（検索・カラム別フィルタ・ソート・合格チェック・詳細・削除）
- **統計チャート**（得点分布ヒストグラム＋カテゴリ別平均レーダー、ライト/ダークモード両対応）
- **学力ランキング**（上位N名）
- **クラスター分析**（K-means+PCA）— 各クラスターの自動特性ラベル＋代表者表示

### 個人確認
- **コンソールタブ式マルチオープン** — 最大10名を同時にタブで開いて比較可能（←/→/Ctrl+W のキーボード対応）
- 学力試験レーダー（カテゴリ別正答率）+ アンケート傾向レーダー + 面接評価レーダー（複数面接官対応）
- 履歴書情報の全体閲覧
- **学力試験の回答内訳**（問題ごとに正誤を表示）
- 🏆 **合格チェック** — 1クリックで合格者をマーク

### クラスター分析（多様性確保のため）
- K-means(k=2〜8)で受験者を属性グループに分割
- PCA2D散布図 + クラスター中心のレーダー
- **自動特性ラベル**: 各クラスターの「強み（平均より高い）」「弱み（平均より低い）」を抽出
- 多様性確保のためにグループから何名採用すべきか目安を表示

### データ管理
- localStorage 永続化（オプションで Supabase クラウド同期）
- CSV 取込（履歴書・学力試験・アンケート テンプレート付き）
- デモデータ20名（カスタマイズ前提の試験回付き）即投入

## 技術

- 純粋HTML/CSS/JS（フレームワーク不使用）
- CDN: Chart.js v4.4.0 / qrcode-generator v1.4.4 / supabase-js v2
- データ保存: ブラウザ localStorage（既定）+ オプションで Supabase 連携（[SUPABASE_SETUP.md](SUPABASE_SETUP.md) 参照、Free Tier 内で完結）
- 認証: Supabase 連携時のみ（管理者: email/password、受験者: URL + 個別パスワード）
- 公開: GitHub Pages

## ファイル構成

```
zemi-exam-app/
├── index.html
├── css/style.css
├── db/
│   ├── schema.sql        # Supabase スキーマ定義
│   └── rls.sql           # Row Level Security ポリシー
└── js/
    ├── storage.js         # sessions + candidates upsert
    ├── stats.js           # default banks + auto-scoring
    ├── cluster.js         # K-means + PCA(2D)
    ├── supabase-client.js # Supabase 接続・認証
    ├── data-sync.js       # localStorage ↔ Supabase 双方向同期
    └── app.js             # controller
```

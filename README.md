# ゼミ選抜アナライザー (ZemiSelect Analyzer)

ゼミの入試試験 ── 履歴書・学力試験・アンケート ── をWEB上で受け付け、受験者を多面的に分析するシングルページWebアプリです。

## 主な機能

- **試験受験フォーム**（4ステップウィザード）
  - ① 履歴書記入（受験番号・氏名・GPA・志望動機 など）
  - ② 学力試験（論理・英語・専門・統計・記述・プレゼンの6科目／各100点）
  - ③ アンケート（10項目を5段階評価＋自由記述）
  - ④ 確認・送信
- **ダッシュボード** — 受験者数・平均総合点・得点分布・科目別平均レーダー
- **受験者一覧（履歴）** — 検索／ソート／詳細／削除／JSON入出力
- **個別分析（プロフィール）** — 学力レーダーチャート＋アンケートレーダーチャート＋履歴書情報＋自由記述／印刷対応
- **上位者ランキング** — 総合点・学力・アンケート別に上位N名を表示
- **クラスター分析** — K-means（k=2〜8）+ PCA 2D散布図＋中心特性レーダー
- **採点ウェイト設定** — 学力試験とアンケートの配点比率を変更可能
- **デモデータ投入** — 20名のサンプルデータでクラスター分析を即確認可能

## 技術

- 純粋HTML/CSS/JS（フレームワーク不使用、CDNはChart.jsのみ）
- データ保存：ブラウザ localStorage（JSON入出力でバックアップ可能）
- 公開：GitHub Pages で無料ホスティング可能

## 使い方

1. `index.html` をブラウザで開く
2. `設定` タブで **デモデータを投入** を押すと20件のサンプルが入り、各機能を確認できます
3. 本番運用時は `試験を受ける` タブのURLを受験者に共有してください

## ファイル構成

```

```

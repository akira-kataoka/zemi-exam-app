💾 システム

📋 試験回の基本情報

この試験回（セッション）の名前と日時・場所・目標などを登録できます。受験者には公開されません（運営用メモ）。

📐 面接 評価項目（試験回ごと）

面接で評価する観点を試験回ごとにカスタマイズできます。各項目は1〜5の5段階評価。
「📌 デフォルトとして保存」で 次に作る試験回も同じ項目で始まるようになります。

🎤 面接スケジュール 設定

面接の日時枠を設定して、未スケジュール受験者を一括で自動配置できます。

⏱ 面接タイムライン

予定 進行中 遅延中 実施済 遅延で実施 💡 カードをドラッグして時間枠を入れ替え可能

⏱ 学力試験 時間制限

試験の 終了時刻 は 設定 → 履歴書 → 受付制御 の「学力試験 終了日時」を使用します。
ここで設定する 猶予時間 は、終了時刻後に提出のみ受け付ける時間です。

📚 学力試験 問題管理（試験回ごと）

この試験回で出題する選択式問題を作成・編集できます。各問題はカテゴリ・配点・選択肢・正解を設定可能で、受験者の回答は自動採点されます。

📋 アンケート 問題管理（試験回ごと）

受験者に問う5段階評価の項目を作成・編集できます。

🔐 受験申込の合言葉（任意）

公開URLに合言葉を設定すると、申込フォームを開く前に入力を求められます。SNS等で告知する際の意図しない申込を防げます。空欄なら誰でもアクセス可能。

📨 配布メッセージテンプレート

差し込み変数一覧（クリックで展開）

{{name}}=氏名 / {{lastName}}=姓 / {{firstName}}=名 / {{examineeId}}=受験番号 / {{password}}=パスワード / {{url_resume}} {{url_academic}} {{url_survey}} = 各URL / {{interview_date}} {{interview_time}} {{interview_datetime}} = 面接日時 / {{sessionName}} = 試験回名

🏫 学部・学科の選択肢

受験者が履歴書で選択できる学部と、その配下の学科を設定します。各学部をクリックで詳細展開。

📄 履歴書 追加質問

標準フィールド（受験番号・氏名・大学・GPA・志望動機など）以外に、この試験回独自の追加質問を設定できます。

🔓 受付制御（手動ON/OFF + 日時スケジュール）

手動ONの上で開始/終了日時を指定すると、その期間だけ自動で受付状態になります。手動OFFはスケジュールに関わらず常に停止です。空欄なら期限なし。

📋 アンケート

受験番号と各項目の5段階評価を入力

テンプレート内容を見る
1行目: 受験番号, 項目1, 項目2, ..., 力を入れた活動, 挑戦したいこと ← ヘッダー
2行目以降: 受験番号と各項目の 1〜5の数値 + 自由記述
※カラム順は 設定 → アンケート の項目順と一致
※質問文の確認は 設定 → アンケート の編集画面で

💡 同じ受験番号でアップロードすると既存データに上書きされます（追加情報を後から取り込む場合に便利）

⚙ 管理

📚 学力試験

設定 → 履歴書 → 履歴書フォーム設定: 学部・学科の選択肢、追加質問を設定。

📱 受験者向けの流れ

①📝 受験申込（公開URL）
QRコード読取
→
最小情報入力
→
受験番号取得

受験者は配布されたURL・QRから申込フォームを開き、氏名・連絡先・所属学部を入力。受験番号が自動発行されます。

②📄 履歴書 + 📋 アンケート（個別URL）
管理者からLINE/メール受信
→
専用URLクリック
→
フォーム提出

受験者は配布されたメッセージから自分専用URLを開き、履歴書（顔写真・志望動機など）とアンケート（5段階評価）に回答。

③📚 学力試験
専用URLアクセス
→
選択式問題
→
自動採点

受験者は選択式問題に回答。提出後に自動採点され、正答率がその場で表示されます。

④🎤 面接
配布メッセージで日時通知
→
指定時刻に対面

面接日時はあらかじめ配布メッセージで通知。当日は対面・オンラインで実施し、評価は管理者が記録。

💡 便利な機能・ヒント

🔍
受験者一覧の絞り込み
「🔍 詳細検索」ボタンで各カラム個別検索が可能。学力 ≥70、アンケート ≥3.5 のような数値条件も使えます。
📊
提出状況カードをクリック
ダッシュボードの統計カード（履歴書・学力・アンケート・面接）をクリックすると、提出者と未提出者を時系列で確認できるモーダルが開きます。
📥
紙回答のCSVインポート
紙で受け取った履歴書・学力試験・アンケートは 設定 → データ から CSV テンプレートをDL→入力→アップロードで一括取込できます。
🎯
クラスター分析の活用
単純な学力順だけでなく、系統別に1〜2名ずつ採用することで多様性のあるゼミ編成が可能。各クラスターの「代表的な受験者」を参考に。
🔄
状態の自動保存
開いていたタブ・検索条件・選択していた受験者は自動保存されます。リフレッシュしても続きから作業できます。
🔐
受験申込の合言葉
設定 → 履歴書 → 受験申込URL でパスコードを設定すると、申込フォームが合言葉付きに。意図しない一般申込を防げます。
⌨
キーボードショートカット
/ 検索バーにフォーカス　/　? このヘルプを開く　/　Esc モーダルを閉じる
🌙
ダークモード切替
画面右上の 🌙 / ☀ ボタンで明暗を切替できます。設定はブラウザに保存され、次回以降も維持されます。グラフ色も自動的に追従。
📱
スマホでの試験回バー折り畳み
スマホ表示時は試験回バーの ▲ ボタンでフェーズ状態などの詳細表示を折り畳んで省スペース化できます。
📧
メール・電話のワンタップ起動
個人画面の メール アドレスをクリックすると標準メーラーが、電話 番号をタップすると電話アプリが起動します。
🏆
最高/最低得点カードから個人画面へ
ダッシュボードの「最高得点」「最低得点」カードをクリックすると、その受験者の個人画面に直接ジャンプできます。
☁
Supabase によるクラウド同期（オプション）
SUPABASE_SETUP.md の手順で Supabase 無料プロジェクトを接続すると、複数端末でデータ共有可能。設定 → データ の「☁ クラウド同期」カードで手動 push/pull もできます。

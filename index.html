📚 学力試験 問題管理（試験回ごと）

この試験回で出題する選択式問題を作成・編集できます。各問題はカテゴリ・配点・選択肢・正解を設定可能で、受験者の回答は自動採点されます。

📋 アンケート 問題管理（試験回ごと）

受験者に問う5段階評価の項目を作成・編集できます。

🔐 受験申込の合言葉（任意）

公開URLに合言葉を設定すると、申込フォームを開く前に入力を求められます。SNS等で告知する際の意図しない申込を防げます。空欄なら誰でもアクセス可能。

📨 配布メッセージテンプレート

差し込み変数一覧（クリックで展開）

{{name}}=氏名 / {{lastName}}=姓 / {{firstName}}=名 / {{examineeId}}=受験番号 / {{password}}=パスワード / {{url_resume}} {{url_academic}} {{url_survey}} = 各URL / {{interview_date}} {{interview_time}} {{interview_datetime}} = 面接日時 / {{sessionName}} = 試験回名

🏫 学部・学科の選択肢

受験者が履歴書で選択できる学部と、その配下の学科を設定します。各学部をクリックで詳細展開。

📄 履歴書 追加質問

標準フィールド（受験番号・氏名・大学・GPA・志望動機など）以外に、この試験回独自の追加質問を設定できます。

🔓 受付制御（手動ON/OFF + 日時スケジュール）

手動ONの上で開始/終了日時を指定すると、その期間だけ自動で受付状態になります。手動OFFはスケジュールに関わらず常に停止です。空欄なら期限なし。
